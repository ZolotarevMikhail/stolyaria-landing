# Столярия — демо-лендинг «Создание сайта»

Одностраничный сайт мебельной мастерской. **Компания вымышленная**, страница собрана как
демонстрация работы для витрины GitHub: клиенты видят пример «продадущего» лендинга,
снятого под реальную нишу мебельщиков.

## Что демонстрирует

- **Структура продающего лендинга**: оффер → доказательства (работы) → процесс → порядок цен → FAQ → одна заявка, повторенная CTA.
- **Автономность**: один HTML, стили и скрипт локальные, внешних библиотек и CDN нет, шрифты системные. Открывается двойным кликом.
- **Устойчивость без JavaScript**: контент виден даже со скриптом, отключённым в браузере (появление блоков прячет и проявляет сам скрипт).
- **Адаптив**: телефон (390px) и компьютер, без горизонтального скролла; анимации только через `transform`/`opacity`, уважение `prefers-reduced-motion`.
- **SEO-база**: уникальный title и description, один H1, alt у всех картинок, размеры картинок, Open Graph и Twitter Card, canonical, разметка LocalBusiness, robots.txt и sitemap.xml.
- **Юр-минимум**: подпись согласия на обработку данных под формой, дисклеймер «демонстрационный проект» в футере.

## Из чего собран

| Файл | Что это |
|---|---|
| `index.html` | сам лендинг |
| `style.css` | стили (палитра и правило — в `DESIGN.md`) |
| `script.js` | появление блоков + демо-форма-заглушка (сообщает, что заявка в реальном проекте уйдёт на телефон) |
| `img/` | 4 изображения, сгенерированы нейросетью **Pollinations (модель flux)**, серия в едином стиле: общее описание + свой seed на каждую |
| `DESIGN.md` | бренд-система: палитра, шрифты, герой, tone of voice |
| `robots.txt`, `sitemap.xml` | SEO-обвязка |

## Как посмотреть

1. Скачать папку и открыть `index.html` двойным кликом (или открыть предпросмотр GitHub Pages).
2. В браузере: телефон-вид через DevTools (шаблон iPhone) и полный экран — версии обе собраны.
